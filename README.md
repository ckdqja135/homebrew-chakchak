# 착착 (Chakchak) Homebrew

대화와 작업물을 하나의 협업 공간으로 연결하는 착착의 맥 데스크톱 앱을 Homebrew 로 설치합니다.

## 설치

```sh
brew install --cask ckdqja135/chakchak/chakchak
```

- macOS 13 이상, 애플 실리콘·인텔 모두 됩니다.
- 처음 열 때 막히면 **시스템 설정 → 개인정보 보호 및 보안**에서 '그래도 열기'를 누르세요.
- 앱을 켜면 같은 와이파이의 착착을 찾아 참여하거나, 초대 링크로 참여하거나, 이 PC에 서버를 만들 수 있어요.

## 업데이트 · 지우기

```sh
brew upgrade --cask chakchak
brew uninstall --cask chakchak        # 앱만 지우기
brew uninstall --zap --cask chakchak  # 설정(서버 주소 등)까지 지우기
```

## 업데이트 기록

### 1.0.6 (2026-11-05)

- 가상 사무실: 열린 공간에서도 캠을 켤 수 있음 (아래 막대의 캠 켜기)
- 가상 사무실: 캠을 켜면 사람 카드의 캐릭터 얼굴 자리에 실시간 캠 화면이 나오고, 아직 멀리 있는 사람은 캠 아이콘만 보임
- 가상 사무실: 캠과 화면 공유를 같이 하면 공유 화면 오른쪽 위에 공유한 사람의 캠을 작게 겹쳐 보여 줌 (크게 보기에서도)
- 가상 사무실: 캠을 켠 채 회의실에 들어가면 회의 통화에서도 캠이 이어서 켜짐
- 결재: DM 에서 결재를 요청할 때 결재자 목록이 틀리던 문제 고침
- 소개 페이지: 문서·디자인·커스텀 봇 소개 추가
- 로그인·회원가입 안내 문구를 다듬음

### 1.0.5 (2026-11-03)

- 커스텀 봇: 원하는 이름의 봇을 만들고 코드 없이 할 일을 정함 (앱 연동을 커스텀 봇으로 바꿈)
- 커스텀 봇: 외부 서비스 알림 받기 (받는 주소, 받은 JSON 값을 {{필드}} 로 글 모양에 넣음, GET ?text= 도 받음)
- 커스텀 봇: 정해진 시간에 글 올리기·외부 API 불러 결과 올리기 (매일·평일·매주·몇 분마다)
- 커스텀 봇: /명령 으로 외부 API 를 불러 답하기 (입력한 사람에게만 또는 채널에)
- 커스텀 봇: 봇은 초대된 채널에만 글을 올리고, 같은 이름의 봇은 만들 수 없음
- 봇 관리자: 관리자가 지정한 멤버도 봇을 만들고 자기가 만든 봇을 관리
- 이 PC 서버: 같은 PC·와이파이에 띄운 봇 프로그램과 주고받을 수 있게 내부망 주소 허용

### 1.0.4 (2026-11-02)

- 메신저: 내가 보낸 파일에 새 메시지 알림이 뜨던 문제 고침
- 메신저: 착착봇 문서 DM 에서 문서 주소 줄을 숨기고 문서 카드만 보여 줌
- 문서: 데이터베이스 링크 칸의 착착 주소는 새 탭 대신 앱 안에서 열림
- 문서: 문서 수정·데이터베이스 변경 알림의 을/를을 제목에 맞게 씀
- 문서: 게스트가 빈 위키를 열면 만들 수 없는 첫 페이지 안내를 보여 주지 않음

### 1.0.3 (2026-11-02)

- 메신저: 새로 연 창에서 가끔 읽은 위치 동기화와 읽음 표시가 멈추던 문제 고침
- 메신저: 채널을 나가도 다른 탭에 그 채널 메시지가 오던 문제와 나에게 보낸 메모가 안 읽음으로 남던 문제 고침
- 메신저: 보고 있던 채널 이름이 바뀌면 새 이름으로 옮기고, DM 메시지 링크는 받은 사람에게도 같은 DM 으로 열림
- 메신저: 투표는 선택지 2~10개로만 만들고 투표·결재 카드는 고칠 수 없게 함
- 메신저: 휴대폰 화면 머리 단추는 아이콘만, 파일을 10개 넘게 고르면 알림, 알림은 모두 위쪽 가운데
- 링크: 이 PC 서버를 localhost 로 열어도 공유·초대·봇 링크를 같은 와이파이 주소로 만듦
- 문서: 시트 정렬 때 머리글 줄 유지, 데이터베이스 열 이름 저장, 필터 되돌리기, 공유받으면 착착봇 DM
- 할 일·일정: 메시지로 만든 할 일에 원래 메시지 링크 저장, 일정 허들은 초대받은 사람만
- 계정: 메일 설정이 없으면 비밀번호 재설정 링크를 서버 기록에 남기고 앱 메뉴의 서버 기록 열기로 확인
- 워크스페이스: 봇이나 게스트에게 소유권을 넘길 수 없게 함

### 1.0.2 (2026-10-30)

- 사무실: 내 주변 사람을 지도 위 카드로 보여 줌 (가까울수록 또렷하게), 접속한 사람 전체는 접속 수를 눌러 봄
- 사무실: 사람 카드, 접속 목록, 캐릭터를 누르면 따라가기, 내 위치로 초대하기, 그 사람에게 이동, 마이크 크기 조절
- 사무실: 찌르면 몸 앞으로 손가락이 나오고 찔린 사람이 좌우로 흔들림
- 사무실: 조작 안내를 이동과 찌르기 키 모양으로 보여 줌
- 사무실: 저전력 모드 안내가 남던 문제와 연결이 잠깐 끊긴 뒤 위치가 되돌아가던 문제 고침
- 문서: 문단 댓글 단추가 마우스를 옮기는 사이 사라지던 문제 고침, 본문을 화면 너비만큼 넓힘
